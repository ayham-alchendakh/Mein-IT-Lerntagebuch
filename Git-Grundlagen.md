# Git Grundlagen 

## Was ist Git?
Git ist ein versionsverwaltungssystem.

Mit Git kann ich Änderungen an Dateien speichern und verwalten .

## Wichtige Git-Befehle


- git init: Ein Repository erstellen
- git status: Den aktuellen statues anzeigen
- git add: Änderungen speichern
- git log: Die commit-historie anzeigen

##Was ist Github?
Github ist eine plattform, auf der ich meine projekte online speichern und mit anderen teilen kann
